# **App Name**: Right Focus International

## Core Features:

- Home Page Design: Home Page: Showcase services and values through an engaging hero section, about preview, and core services grid.
- About Us Page: About Us Page: Detail company history, mission, vision, and core values.
- Services Page Design: Services Page: Dedicated sections for each service area with descriptions, images, and hover animations.
- Contact Us Page: Contact Us Page: Include a contact form, details, and a quick enquiry call-to-action.
- Interactive Animations: Include smooth, scroll-triggered animations (fade-ins, parallax, counters, text reveals, image slide-ins) for an engaging user experience.
- Sticky Navigation: Sticky Navigation: Implement a sticky top navigation bar with a hover underline animation to ensure easy site navigation.
- Responsive Design: Mobile Responsiveness: Ensure the website is fully responsive across all devices.

## Style Guidelines:

- Primary color: Dark navy (#0A1A2F) for a professional and serious tone.
- Background color: Light grey (#F0F0F0), close in hue to the primary color but almost fully desaturated, provides a clean, modern backdrop, ensuring content and design elements stand out.
- Accent color: Blue (#0056B3) to highlight calls to action and key information.
- Headline font: 'Poppins' (sans-serif) for a geometric, modern, and fashionable appearance.
- Body font: 'Inter' (sans-serif) for a neutral, readable, and objective feel in longer texts. Font pairing complements 'Poppins' for headlines.
- Custom icons and illustrations: Unique icons/illustrations for each service area and key value (avoid overused stock).
- Subtle Animations: Employ scroll-triggered animations to enhance user engagement (fade-ins, parallax, counters, reveals, slide-ins).
- Spacious Layout: Utilize wide, spacious sections to enhance readability and content presentation.
